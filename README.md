# Deep Learning with Python

This repository contains the **source code and practical examples** for studying Deep Learning with Python.

Most of the materials are provided as **Jupyter Notebooks**, covering the progression from fundamental neural network concepts to modern Deep Learning architectures.

## Contents

The repository covers topics including:

* Perceptrons and the fundamentals of neural networks
* Deep Neural Networks (DNNs) for common supervised learning tasks
* Convolutional Neural Networks (CNNs) for image-related tasks
* Recurrent Neural Networks (RNNs) for time-series and sequential data
* Transformers for text and Natural Language Processing (NLP)
* Practical implementations and experiments using Python

The examples are intended to demonstrate how different neural network architectures are constructed, trained, and applied to different types of data.

## Notes

* Most code is provided as **Jupyter Notebook (`.ipynb`) files**.
* The repository focuses on **source code and practical implementation** rather than serving as a collection of theoretical notes or PDFs.
* The examples progress from basic neural network concepts toward more advanced Deep Learning architectures.
